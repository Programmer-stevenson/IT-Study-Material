## If the links show a 404

The repository owner must enable GitHub Pages:

1. Go to repository Settings → Pages.
2. Choose Deploy from a branch.
3. Select main and /(root).
4. Click Save and wait for deployment to finish.

Keep index.html and the topic folders at the repository root.

## Offline access

Download and extract the repository, then open index.html in your browser.
